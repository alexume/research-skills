# Examples

## Causal results architecture

- Table 1: sample, treatment timing, and outcome coverage.
- Table 2: main estimand with confidence intervals and explicit comparison group.
- Table 3: design-specific diagnostic or first-stage evidence.
- Appendix A: alternative samples, estimators, inference, and sensitivity tied to registered threats.

Do not place dozens of unlabeled specifications in Table 2. Use stable model identifiers and explain which threat each appendix alternative addresses.

## Historical-structural architecture

- Table 1: source and measurement coverage by period and territory.
- Table 2: temporal and compositional patterns using comparable measures.
- Table 3: cross-case or cross-period comparison linked to mechanisms and rivals.
- Appendix A: alternative boundaries, classifications, price bases, source regimes, and unresolved contradictions.

Do not merge incomparable periods into a continuous table without visible source-regime and definition flags.
