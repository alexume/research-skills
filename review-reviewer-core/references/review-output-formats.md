# Additional Review Output Formats

## Critical Referee

```qmd
---
title: "Critical Manuscript Review"
format: pdf
toc: true
number-sections: true
---

# Summary
# Main Contribution
# Core Structural Weaknesses
# Conceptual Coherence
# Historical Logic
# Methodological Coherence
# Interpretation of Results
# Literature Positioning
# Structure and Presentation
# Major Revisions Required
# Minor Revisions
# Final Assessment
```

## Internal Editorial Screening

Return:

1. brief manuscript reconstruction;
2. strongest asset;
3. main structural blockers;
4. one recommendation: send to external review, do not send, or invite deep reformulation.

## Fixed Internal Forms

- Do not force prose into checkbox lines.
- Highlight only criteria clearly satisfied when the form cannot display an `X`.
- Keep author-facing and editor-facing comments distinct.
- Do not substitute prestige or rankings for analytical judgment.
