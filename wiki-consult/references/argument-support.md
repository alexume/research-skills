# Argument Support

Use this mode to resolve a specific interpretive bridge, not to survey a topic broadly.

## Define The Burden

State:

- the two or more results, processes, or literatures being connected;
- the proposed relation;
- whether the burden is descriptive, causal, structural, interpretive, or historiographic;
- the required geography, period, population, scale, and object;
- whether the missing element is evidence, citation, mechanism, rival, or author choice.

## Retrieve Before Asking

Follow the standard retrieval order. Prefer a small set of notes with direct fit. Expand only when the first set cannot carry the burden.

Ask the user only when:

- the KnowledgeWiki root cannot be resolved;
- no suitable structured note or source-registry entry exists;
- available notes are provisional or lack the required object, period, geography, or scale;
- raw PDFs, TXT files, or extracted text are needed and permission has not been granted;
- the remaining issue is an authorial choice among defensible interpretations;
- the user may possess an unregistered source essential to the bridge.

For a central bridge, a note that is provisional, lacks verifiable locators, or only summarizes an uninspected source triggers an exact request when no verified structured source can carry the burden. Do not declare that no request is needed merely because narrowing or parking would make the prose safer.

## Classify The Result

- `direct support`: the note or source addresses the relation at the required scope.
- `triangulated support`: several independent notes jointly support the bridge.
- `inferred synthesis`: the relation is reasoned from sources that do not state it directly.
- `rival support`: evidence favors a competing relation.
- `insufficient`: the central burden remains unmet.

Do not convert inferred synthesis into direct support through polished prose.

## Decide The Action

- Draft when support is direct or adequately triangulated.
- Draft positively with one material boundary when support is partial but sufficient.
- Use a precise placeholder for a noncentral citation gap.
- Block finalization of the affected section when a central bridge remains insufficient.
- Park the bridge when it is attractive but unnecessary to the core argument.
- Before narrowing or parking, test whether the remaining architecture still delivers its promised debate contribution. If not, request the missing source or author decision and mark the architecture provisional or blocked.

## Source Or Author Request

When a request is necessary, use:

```markdown
### Request

- Bridge requiring support:
- Evidence or decision needed:
- Required object, geography, period, and scale:
- Current wiki coverage and why it is insufficient:
- Candidate source or source type, if known:
- Consequence if unavailable: narrow / placeholder / park / delete
- Contribution affected if unavailable:
```

Keep the request answerable. Do not ask the user to "provide more literature" without specifying the evidentiary function.
