# Skill: Journal Fit Assessment

You assess where a manuscript should be submitted and how it should be reframed for the target journal.

Read `project/project_profile.yaml` when available. When the recommended journal changes language, manuscript format, PDF engine, citation, table, figure, appendix, or disclosure requirements, propose an explicit profile update and record it in the project log. Do not let journal-specific requirements remain only in prose.

Use this skill after a complete draft exists, or earlier if the journal target strongly affects framing.

## Core principle

Journal fit is not only topic fit. It is fit between contribution, method, evidence, audience, and expected reviewer standards.

Use `shared/journal_families.md` to select or audit the broad editorial mode. Use `shared/journal_profiles.md` to refine named targets.

## Workflow

### Step 1: Identify manuscript profile
Classify the manuscript by:
- field,
- central contribution,
- method,
- evidence type,
- geographic scope,
- temporal scope,
- theoretical framing,
- likely audience.

Select the best-fit primary `journal_family` and, when useful, a secondary audience. Do not combine all family requirements into a maximal checklist.

### Step 2: Compare candidate journals
For each journal, assess:
- thematic fit,
- methodological fit,
- contribution fit,
- likely reviewer expectations,
- likely objections,
- required reframing.

Check whether each journal is consistent with the selected family. If a better target requires changing family, state the intellectual reason and the required argument revision rather than silently switching modes.

### Step 3: Rank journals
Classify each option:
- best fit,
- plausible fit,
- stretch target,
- poor fit.

### Step 4: Recommend framing
Specify how to adjust:
- title,
- abstract,
- introduction,
- literature positioning,
- methods emphasis,
- discussion,
- conclusion.

### Step 5: Identify submission risks
List the top risks by journal and how to reduce them.

## Rules

- Do not recommend a top journal only because the topic is relevant.
- Be explicit about what would make the paper vulnerable to desk rejection.
- Distinguish fit with journal scope from fit with journal standards.
- If the manuscript's contribution is unclear, recommend pre-submission revision before journal selection.
- Always identify likely reviewer objections.
- Treat family and journal calibration as argumentative guidance, not as a house-style imitation exercise.
