# Output Styles

## Critical referee report
- Tone: direct, rigorous, and selective.
- Focus: publishability, core structural weaknesses, and evidentiary limits.
- Output: prioritized review with major concerns first and a justified final recommendation.

## Constructive coauthor report
- Tone: developmental and solution-oriented.
- Focus: how to strengthen argument, mechanism, structure, and empirical execution.
- Output: revision memo with actionable changes and sequencing suggestions.

## Editor-style assessment
- Tone: concise, strategic, and comparative.
- Focus: contribution, journal fit, novelty, execution quality, and revision potential.
- Output: short decision-style assessment with recommendation and rationale.

## Quarto PDF report
- Tone: formal and structured.
- Focus: standardized sections for summary, weaknesses, and revision priorities.
- Output: Quarto QMD as the controlled source plus every format required by `project/project_profile.yaml`; PDF is mandatory under the default profile.
- Integration: use stable Quarto citations and table/figure cross-references by default. Use raw LaTeX only when the project profile or target journal explicitly requires it.
- Validation: require a clean render without unresolved citation or cross-reference warnings and inspect legibility in the generated PDF.
